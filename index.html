About Teja Priyan Showreel Studio

Showreel Studio is a code-driven motion graphics experience built with React, Three.js, GSAP, and the Web Audio API. It features dual cinematic showreels: Swiss Kinetic (Claude Edition) and Neon Pulse (Cyberpunk Glitch), running at 60 FPS with responsive aspect ratios for mobile vertical reels (9:16), desktop widescreen (16:9), and square formats (1:1).
